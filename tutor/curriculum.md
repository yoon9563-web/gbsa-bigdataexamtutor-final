# 시험과 개념 지도

실기 계획 기준은 180분, 100점 만점 중 60점 이상이다. 적용 회차의 안내가 우선이다.

| 유형 | 기준 배점 | 훈련 목표 |
|---|---:|---|
| 1유형 | 3문항, 30점 | 가공·집계한 값을 지정 형식으로 도출 |
| 2유형 | 1문항, 40점 | 분류·회귀, 평가 지표에 맞춘 예측과 CSV 제출 |
| 3유형 | 2문항, 30점 | 통계 검정이나 회귀 분석을 실행하고 지정 결과 계산·해석 |

| 유형 | 개념 태그 | 대표 확인 과제 |
|---|---|---|
| 1 | 자료형·인덱스·필터·빈도 | 여러 조건과 결측 포함 여부를 구분해 행 수 계산 |
| 1 | 그룹 집계·정렬·순위·비율 | 분모·동률 규칙에 맞춰 상위 값이나 키 추출 |
| 1 | 날짜·문자열 | 연월과 월 구분, 파싱·대소문자·결측 처리 |
| 1 | 재필터·다중그룹 | 집계에서 대상 키를 구해 원본에서 추가 계산 |
| 1 | 결측·분위수·이상치·표준화 | 전체/그룹 기준, IQR, 표준편차 기준 확인 |
| 1 | 조인·중복·변환·차분·열 복구 | 키 중복, pivot/melt, 단계별 순서와 유효 행 검증 |
| 1 | 상관·파생변수 | 조건부 상관, 0 분모와 계산 순서 확인 |
| 2 | 문제 판독·전처리·검증·모델 | 타깃·ID 구분, 학습/검증 분리, 미지 범주와 데이터 누설 점검 |
| 2 | RMSE·RMSLE·Accuracy·F1·ROC-AUC | 지표 방향, 라벨/확률/수치 선택, 양성 클래스와 확률 열 확인 |
| 2 | 제출 규격·예외 | CSV 열·행·순서·파일명 재확인, 음수·결측·별도 타깃 파일 처리 |
| 3 | 가설·검정 조건·p값 | 단일/독립/대응 표본 t검정, 카이제곱, 분산분석 중 선택 |
| 3 | 상관·회귀·출력 해석 | 회귀계수, p값, 예측값, 문제에서 지정한 해석 |

보고서의 데이터마님 10·11·12회 동형은 각각 Accuracy, RMSE, RMSLE 실습에 활용할 수 있다. 외부 공개 복원 자료에는 RMSE, ROC-AUC, RMSLE 사례가 있다. 문항마다 제시된 지표와 제출 규격을 직접 읽는다. 1유형의 실전 전환은 필터·집계에서 문자열·날짜·재집계로 넓히고, 이후 결측과 표 변환을 섞는다. 보고서의 색인은 제목과 확인 주제로 정리한 학습 참고이며 모든 세부 풀이가 검증된 범위는 아니다. 3유형 표의 세부 통계 기법은 자체 연습 범위다.
