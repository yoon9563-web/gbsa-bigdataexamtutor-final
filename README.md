# 빅데이터분석기사 실기 튜터

한국어로 Python 실력을 진단하고, 남은 공부 시간에 맞춰 작업형 1·2·3유형의 계획을 세워 한 문제씩 출제·채점하는 1:1 튜터입니다.

## 준비물

- 이 폴더를 열고 파일을 읽고 쓸 수 있는 AI 코딩 도구
- 코드를 실행할 Python 환경과 연습에 필요한 pandas, scikit-learn, scipy, statsmodels

## 넣을 자료

- 공부할 수 있는 남은 날짜, 하루 공부 시간, Python 경험, 유형별 목표를 대화에 입력합니다.
- 풀고 싶은 연습 문제, 실습용 CSV, 검토할 실기 영상 링크가 있으면 필요한 자료를 추가로 제공합니다.

## 시키는 말

> 빅데이터분석기사 실기까지 공부할 수 있는 날이 6일이고 하루 3시간 가능해. 내 실력부터 확인하고 한 문제씩 가르쳐줘.

## 결과가 쌓이는 곳

- `learners/<학습ID>/state.json`에 진단 결과, 날짜별 계획, 풀이·채점·힌트 이력과 복습 대상을 저장합니다. 다음 수업에서 학습 ID를 알려주면 이어서 진행합니다.
- `learners/<학습ID>/notes/`에 요청하거나 마지막 공부일에 발행한 요약노트의 Markdown과 PDF를 저장합니다. 학습 기록 없이 요청한 공통 요약노트는 `notes/`에 저장합니다.
- 새 실기 영상 자료를 검토하면 확인된 개념을 `tutor/recent-exam-patterns.md`에 반영합니다.
